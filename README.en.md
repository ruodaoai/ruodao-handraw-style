# Handraw Style Gallery

A numbered gallery of 366 hand-drawn styles with 167 layout motifs and 36 classic single-colour palettes. Browse by thumbnail, pick a style number, generate with the model you choose, and share results to the plugin case wall.

## What it does

- **Numbered style library** - every style has a stable number (001-288+), preview image and bilingual prompt guidance, so a style can be referenced reliably across sessions.
- **Layout motifs** - 167 composition templates (grid, frame, poster, diagram and so on) that can be combined with any style.
- **Palettes** - 36 single-colour themes for a coherent look.
- **Generation** - pick a style plus a model and send the composed prompt straight to the image model.
- **Sharing** - publish a result to the plugin case wall.

## Requirements

- Ruodao desktop host with at least one image model configured.

## Permissions and privacy

- `network`, `process`, local storage.
- Prompts and images stay local unless you explicitly share a case.
